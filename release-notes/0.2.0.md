# strafe-tatoalo 0.2.0

The first release of the tatoalo fork, based on upstream Strafe 0.1.2.

- Switch Spaces instantly with Control–Left and Control–Right, including BetterMouse gestures that send those shortcuts.
- Check for updates from the menu bar, read release notes, and install updates without rebuilding locally.
- Enable or disable automatic update checks from the menu.
- Signed and notarized Apple Silicon app and installer, with a dedicated fork identity.
- Existing transition-speed and hotkey preferences migrate on first launch.

Disable macOS's “Move left a space” and “Move right a space” keyboard shortcuts before enabling Strafe's Control–Arrow hotkeys. Quit the upstream/local Strafe app before launching this fork, and grant Accessibility to **strafe-tatoalo** once.
